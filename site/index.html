Comment ça marche

Trois gestes, zéro clavier.

Dans un mail, Slack, Notion, ChatGPT ou ton code : là où il y a un curseur, OxoFlow écrit.

1

Maintiens fn

Une petite pastille apparaît en bas de l’écran et montre ta voix en direct. Sur Windows : Ctrl + Alt + Espace.

2

Parle normalement

Pas besoin de dicter la ponctuation : les « euh » disparaissent, les majuscules et les espaces se placent seuls.

3

Relâche

Moins d’une seconde plus tard, le texte est collé là où tu écrivais. Ton presse-papiers est remis comme avant.

Fonctions

Rapide, précis, à toi.

100 % local

Whisper tourne sur ta puce ou ta carte graphique. Hors ligne une fois le modèle téléchargé.

Moins d’une seconde

MLX sur le GPU des Mac, CUDA sur les PC NVIDIA, repli sur le processeur sinon.

Ton vocabulaire

« n huit n » devient n8n, « x field » devient Higgsfield. Apprends-lui tes noms propres.

Mise en forme IA

En option, un modèle local (LM Studio, Ollama) garde ta correction quand tu te reprends.

Snippets

Dis « ma signature », OxoFlow écrit le texte complet : adresse, lien, formule de politesse.

Historique

Toutes tes dictées, par jour, avec recherche. ⌃⌘V recolle la dernière.

Barre Flow

Une fine capsule en bas de l’écran : survole-la pour le rappel, clique pour dicter.

Open source

Licence MIT. Le code est sur GitHub : lis-le, modifie-le, construis-le toi-même.

Tout dans la barre des menus.

Un clic sur l’icône : l’état du moteur, tes statistiques du jour, des interrupteurs rapides, tes dictées récentes et un bouton pour dicter. Pendant que tu parles, la pastille affiche le spectre de ta voix, puis la phrase collée.

Télécharger

Prêt en deux minutes.

Les applications ne sont pas signées par Apple ni par Microsoft (c’est payant) : il y a un écran à passer au premier lancement, voici comment.

Mac

  1. Ouvre le .dmg et glisse OxoFlow dans Applications.
  2. Si macOS refuse de l’ouvrir : Réglages Système › Confidentialité et sécurité, puis Ouvrir quand même.
  3. Laisse-toi guider : micro, Accessibilité, touche fn, et un premier essai.
macOS 13.5 ou plus récent, puce Apple (M1 et suivantes) · modèle de 1,6 Go téléchargé une fois OxoFlow pour Mac

Windows

  1. Lance OxoFlow-Setup.exe (aucun droit administrateur).
  2. À « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même.
  3. Appuie sur Ctrl + Alt + Espace et parle.

Est-ce que ma voix est envoyée quelque part ?

Non. La transcription se fait sur ta machine. La seule connexion est le téléchargement du modèle au premier lancement (depuis Hugging Face). Même la mise en forme IA, si tu l’actives, n’accepte qu’un serveur local.

Pourquoi l’app n’est-elle pas signée ?

Signer une app coûte un abonnement chez Apple (99 $ par an) et chez Microsoft. OxoFlow est gratuit : en attendant, le code est entièrement public sur GitHub et les fichiers sont fabriqués automatiquement par GitHub à partir de ce code.

Quelle langue ?

Français et anglais sont réglés finement ; la détection automatique reconnaît aussi la plupart des autres langues prises en charge par Whisper.

Et les Mac Intel ?

Pas encore : la version Mac utilise MLX, réservé aux puces Apple.
